Travel Studio 隱私權政策

條款版本：2026-11-09

前言

Travel Studio（以下稱「本服務」）提供旅遊行程建立、編輯、儲存、分享、公開展示及多人共同編輯等功能。本服務由 Travel Studio 官方網站「營運資訊」所載的營運法人（以下稱「本平台」）提供。本平台依據中華民國《個人資料保護法》及其他適用法令，蒐集、處理及利用使用者資料，並以資料最小化、權限控管及目的限制為原則。

新建立的行程預設為私人；公開行程、允許複製、原創內容再利用與商業宣傳，分別依使用者的設定與授權辦理。旅行計畫中的「想去」不等於實際到訪，預估費用亦不等於實際消費。

第一條　蒐集者、委託處理及聯絡方式

一、本平台為本服務所蒐集個人資料的蒐集、處理及利用者，其法定名稱、登記地址、聯絡信箱及個資權利申請方式，於本服務官方網站「營運資訊」及「聯絡我們」頁面公開揭露；使用者得透過該管道洽詢或提出個人資料權利請求。

二、本平台得委託第三方辦理系統開發及維運、網站託管、身分驗證、資料庫、照片儲存、資訊安全、備份及其他提供本服務所必要的技術作業。本平台對受託者設有目的、權限、保密、安全及刪除／返還之契約要求；受託者不得將可識別使用者之個人資料用於委託範圍以外的目的。

三、開發或維運受託者若經本平台依契約另行授權接觸或利用已完成適當去識別化及彙整之統計成果，其用途限於受託產品之效能分析、品質改善與經明確約定之技術研究，不得取用可識別使用者之行程、帳號、照片、備註或原始事件資料作自身業務、廣告或資料販售。是否開放、所涉資料種類及契約權利，依正式委託契約與相關告知規定辦理；未經授權，受託者不享有前述權限。

第二條　蒐集目的

本平台蒐集、處理及利用資料的目的為：

  1. 提供行程建立、編輯、儲存、閱讀、分享及多人同步協作。
  2. 進行帳號登入（Google、LINE、Apple 或 Email 驗證碼）、匿名協作者驗證、帳號連結、權限及帳號管理。
  3. 管理地點、住宿、時間、交通、預算、訂位、照片、郵戳、備註及匯出資料。
  4. 提供公開行程瀏覽、心心、排行及行程複製功能。
  5. 記錄服務使用事件，用於功能運作、版本紀錄、提醒處理、同步、異常排查及服務品質監測。
  6. 維護資訊安全、防止未經授權的存取、垃圾內容、惡意檢舉及刷心心。
  7. 處理檢舉、客訴、服務支援、法律爭議及法定義務。
  8. 在符合適用法律且已取得必要授權時，分析去識別化的旅遊行為資料，以改善服務、產生趨勢及推薦。
  9. 在使用者分別授權的範圍內，公開展示、允許行程複製、再利用原創內容或用於商業宣傳。

提供基本服務所必要的資料處理，與非必要統計、公開展示及其他選用授權分別管理。

第三條　蒐集的資料類別

一、登入帳號資料

瀏覽本網站及公開行程不須登入；使用者可先填寫目的地與起訖日期，按下「建立行程」時才需登入，登入完成後返回本網站建立行程，無須重新輸入原表單。

本服務支援以下登入方式，依使用者選擇的方式與實際授權範圍，本平台可能取得：

  1. Google：Google 使用者識別碼、電子郵件地址、顯示名稱、頭像。
  2. LINE：LINE 使用者識別碼、顯示名稱、頭像；電子郵件地址僅於使用者另行授權時取得。
  3. Apple：Apple 使用者識別碼、姓名（僅首次登入提供）、電子郵件地址或 Apple 提供的轉發信箱。
  4. Email 驗證碼：電子郵件地址及驗證紀錄。

上述資料用於身分驗證、帳號管理、行程歸屬與安全防護。本服務目前不要求 Gmail、Google Drive、通訊錄、LINE 好友名單或訊息內容的讀取權限。對 Google API 取得的資料，本平台依 Google API Services User Data Policy 辦理；對 LINE 與 Apple 取得的資料，分別依 LINE Developers 及 Apple 的開發者條款辦理。本平台不將登入資料出售予資料經紀商或用於未經授權的廣告定向。

同一使用者以不同方式登入時，若電子郵件地址相同，本平台得將其連結為同一帳號；使用者亦可於帳號設定主動連結或解除連結其他登入方式。使用 Apple 轉發信箱或未提供電子郵件的 LINE 帳號，需由使用者手動連結。

二、匿名共同編輯資料

收到有效編輯邀請的朋友，可在 LINE 等瀏覽器中輸入暱稱並確認必要告知後加入。系統為其建立匿名驗證身分、識別碼及工作階段，並記錄授權、操作與修改歷史。暱稱不等於可靠的身分證明；匿名使用者仍可能因其識別碼及操作資訊而構成可識別的個人資料。

匿名身分不能建立自己的行程、公開行程、產生邀請連結或按心心。匿名協作者可選擇綁定任一支援的登入方式；成功綁定後，原有身分、權限及編輯紀錄延續，不另建帳號。於 LINE 等應用程式內建瀏覽器中，Google 與 Apple 登入可能不支援，使用者可改用 LINE 登入，或依系統引導改用一般瀏覽器。

未綁定的匿名使用者若清除瀏覽器資料或遺失工作階段，之後再次透過有效邀請連結加入，會建立新的匿名身分。舊操作紀錄將按本政策保存；行程擁有者可移除重複或不再需要的協作者。

三、行程與協作資料

包括行程名稱、國家與城市、旅行日期、當地時區、同行人數、行程來源及複製自哪一份行程、景點或餐廳、住宿、位置或地圖連結、卡片類型、排序、開始與結束時間、是否固定時間、停留時間、交通方式與預估交通費、預估與實際花費、幣別、每人或整團費用、付款者、已付款及訂位狀態、提醒日期、訂位確認資訊、照片、備註、自訂郵戳名稱及紀錄、版本與協作者操作紀錄。

為降低資料公開風險，訂位確認碼、付款細節、私人備註及同行者識別資料不會因行程設為公開而自動公開。使用者亦不應在自由文字中輸入不必要的敏感個資。

四、實際到訪及消費紀錄

自行程出發日起，使用者可將每張卡片標記為「去了／沒去／未標記（未知）」，並可選填實際花費。未標記不會自動視為已到訪或未到訪。本平台區分計畫到訪與實際回報，亦不會把預估費用當成實際消費。星等、旅後評語及旅後照片屬日後新增功能，啟用前另行更新相關告知。

五、服務使用事件與安全紀錄

包括建立行程、新增或移動項目、設定時間或花費、標記到訪、複製或開啟邀請、加入協作、公開或取消公開、按心心、複製行程、開啟分享連結、匯出資料，以及經本平台轉址開啟的外部連結點擊紀錄（例如地圖、官方網站或訂位網址）。亦可能包含事件時間、行程識別碼、操作者類型、匿名狀態、裝置類型、必要的 IP／瀏覽器資訊、錯誤及安全紀錄。

服務使用事件的事件內容欄位不包含電子郵件、暱稱、備忘或其他自由文字。但事件識別碼若可與個人帳號或行程連結，該紀錄仍依個人資料規範處理；技術性安全日誌可能另含為防護服務所必要的資訊。

第六條　資料統計與行程授權（分項）

一、提供服務所必要之處理

本平台為保存、同步及分享使用者指定的行程，得依必要目的處理相關資料。不同意必要處理可能無法使用需登入或編輯的功能。

二、去識別化統計及服務改善

本平台在清楚告知並取得使用者對非必要統計用途的個別同意後，得將適當處理的地點、時段、預估與實際花費、交通、到訪及互動資訊，用於彙整熱門地區、改善功能、分析服務品質及提供推薦的基礎資料。使用者可於「隱私設定」撤回此項同意；撤回後，新增資料不再納入此項統計。不同意或撤回，不影響基本行程編輯與共同編輯。

統計結果若仍可經合理方式連回特定個人，仍依個人資料規範處理。經不可回復之去識別化處理、依法已不屬於個人資料之彙整成果，本平台得於原定目的範圍內保存及利用；此類處理以本政策告知為之，其範圍與方式由本平台依適用法律認定。

三、公開展示

行程預設「私人」，擁有者可選「持連結觀看」或「公開」。設為公開前，本平台會提供公開內容預覽及必要的公開展示授權確認。公開展示授權不等同允許其他使用者複製原創內容，亦不等同同意平台將照片或原創文字用於另外製作的推薦文章或廣告。

四、允許其他使用者複製

本平台對公開行程提供獨立的「允許其他使用者複製行程」開關，預設開啟；擁有者在公開設定畫面可清楚看到並於公開前或公開後隨時關閉。關閉後其他人仍可查看公開行程，但不能經本平台一鍵複製。複製產生的新行程會記錄來源。共同編輯者於加入行程時，已同意其新增內容隨行程公開展示及複製；擁有者仍應確認由第三方（非協作者）提供的內容已取得適當權利。

公開行程的結構化資料（如地點、時段、花費）得在符合第六條第二項的同意、去識別化與合法目的範圍內，納入統計與推薦分析；不以授權平台重用原創照片、文字作為必要條件。

若本平台希望另行複製、編輯、刊登使用者的原創照片、介紹或評語於平台推薦頁、宣傳素材或獨立內容，須取得可辨識素材及用途的獨立選用授權。使用者拒絕此項授權仍可公開其行程。

共同編輯者可依權限查看同一行程中的日程、住宿、預算及備註，使用者不應在共用資料中輸入不希望協作者知道的敏感資訊。觀看連結與編輯邀請屬不同權限；邀請連結可能代表編輯憑證，應審慎保管。擁有者可撤銷編輯邀請、移除協作者，或取消公開。

公開行程應遮蔽訂位確認碼、付款明細、私人備註及其他不適合公開的資料；但公開期間第三方仍可能自行截圖，取消公開不能保證收回已保存的外部副本。

不登入者仍可瀏覽公開行程，或憑有效邀請加入匿名共同編輯，但不能自行建立行程。匿名共同編輯者按心心時，系統將引導綁定任一支援的登入方式，而不是另建帳號。不提供必要暱稱無法匿名加入；不填時間、預算、到訪狀態僅使相關功能不完整，未標記到訪一律為未知。不同意非必要統計、原創內容再利用或商業宣傳，仍可使用基本服務；未授權公開展示則不能將行程設定為公開。

第十一條　資料保存、匯出與刪除

一、正式帳號及行程：使用者可匯出自己的行程 JSON 並申請刪除帳號。經完成必要身分確認，主要系統中無其他合法保存必要的個人資料，原則上於 30 日內完成刪除；公開行程同步下架。涉及他人共同行程的內容，得在合法必要範圍內保留並刪除或去識別化已無必要的帳號識別。

二、匿名共同編輯者帳號：未綁定登入帳號且連續 12 個月無登入、編輯或其他有效活動的匿名帳號，原則上進入刪除流程；有效協作權限與共同行程的內容是否仍需保留，依必要性及適用法律評估。此期限為本平台採行的預設管理期間，除法律另有規定外，相關資料依本政策處理。

三、備份：完成刪除程序後，已刪除的資料原則上於不超過 90 日的備份輪替期間內清除或覆寫；法律義務、未結爭議或資安事件必要留存者除外。

四、一般操作與安全日誌：原則上保存 180 日；涉及事故、法律爭議或檢舉者得在必要範圍內延長。後台管理操作的稽核紀錄與一般日誌分開保存，依本平台內控及法定必要期限管理，不受前述 180 日期限限制。

五、服務使用事件：能連結特定帳號或行程的原始事件紀錄，依提供服務、安全與資料保存政策管理；使用者刪除帳號後，該等資料於無其他合法保存必要時一併刪除或不可逆去識別化。依第六條第二項合法處理並完成去識別化的彙整統計成果，得在原定目的範圍內保存。

六、檢舉、申訴及法定保存資料：依處理爭議、防止濫用及法令所需期間保存；目的消失或期限屆滿後，依法刪除或停止利用。

第十二條　未成年人保護

本服務主要提供具有相應法律行為能力的人使用。未滿 18 歲者應依中華民國法律，由法定代理人提供必要同意或協助。使用者應避免公開未成年人的詳細旅行日期、住宿位置及其他可識別的行蹤資料；如有違規或涉及未成年人權益之檢舉，本平台將依適用法律採取適當措施。

第十三條　政策修改

本政策可能因功能、資料用途或法律調整而更新。本平台將公布新版、生效日及必要的差異說明；涉及新目的或依法應取得同意的處理，將在實施前另行徵求必要同意。政策聯絡與權利申請請使用本網站正式公布的「聯絡我們」入口。
